# 音樂檔放這裡

請放**免版稅**的 mp3，檔名一定要和下面一樣（全部小寫）。缺哪個檔案，網站就安靜跳過那個聲音，不會壞掉。

| 檔名 | 什麼時候播 |
|---|---|
| `idle.mp3` | 開場前、準備階段、頒獎前的待機室（循環） |
| `intro.mp3` | 主持人介紹選手（播一次） |
| `break.mp3` | 中場休息（循環） |
| `lunch.mp3` | 午餐（循環） |
| `drumroll.mp3` | 頒獎揭曉前（第 6 階段） |
| `celebrate.mp3` | 揭曉獲勝組別（第 6 階段） |
| `bell.mp3` | 時間到 |
| `ding.mp3` | 剩 30 秒提醒 |

上傳方式：GitHub 的 repo 頁面 → 點進 `audio` 資料夾 → **Add file → Upload files** → 把 mp3 拖進去 → **Commit changes**。
